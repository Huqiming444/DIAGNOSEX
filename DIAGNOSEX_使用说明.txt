DIAGNOSEX 使用说明
==================

一、快速启动
------------
1. 把整个文件夹复制到你想放的位置（桌面、D盘、U盘都可以）。
2. 确认文件夹里有以下 4 个文件：
   - DIAGNOSEX.py
   - run_DIAGNOSEX.bat
   - requirements.txt
   - 中药上市公司2023-2025年报财务数据.csv
3. 双击 run_DIAGNOSEX.bat。
4. 首次运行会自动安装依赖，约 2-5 分钟，请等待黑窗口提示“正在启动”。
5. 浏览器自动打开 http://localhost:8502。
6. 用完直接关闭黑窗口即可停止服务。

二、左侧栏三项设置
------------------
- 基准年份：建议选 2025（最新年报）。
- 对标组：中小企业诊断建议选“中小型上市公司（营收 ≤ 中位）”。
- 权重口径：中小企业诊断建议选“中小企业口径（推荐）”。

三、四个页签
------------
1. 基准与排行：68 家上市公司健康度排名、评级、领先/待改善榜。
2. 企业详情：单家公司三年财务走势、六维度雷达、指标分位。
3. 行业全景：三年总量、盈利中位、亏损面、风险—回报散点。
4. DIAGNOSE 诊断台：给中小企业录入财务数据，得到评分、评级、改进建议、情景模拟和报告。

四、诊断需要准备的 11 项数据
-----------------------------
企业名称、营业收入（亿元）、上年营业收入（亿元）、归母净利润（亿元）、
上年归母净利润（亿元）、毛利率（%）、ROE（%）、资产负债率（%）、
总资产（亿元）、经营现金流净额（亿元）、研发费用率（%）。

五、批量诊断
------------
在“DIAGNOSE 诊断台”选择“批量上传 CSV”，先下载模板，按列名填好后上传。
支持 UTF-8 和 GBK 编码（Excel 默认 CSV 可直接读取）。

五之二、诊断结果导出（每家企业一份）
------------------------------------
1. 单户/示例诊断：诊断完成后在“报告导出”处有三个按钮——
   · 诊断结果单页（HTML · 一页纸）：一页 A4 的精简版，适合直接发给企业；
   · 诊断报告（Markdown）：纯文本，便于二次编辑；
   · 完整商业报告（HTML）：七章详版，适合作为融资材料附件。
2. 批量诊断：上传后会生成“逐家诊断结果单页”区域——
   · “打包下载全部单页（ZIP）”：一次拿到所有企业各自的单页；
   · 展开“逐家单独下载”：可单独取某一家。
3. 企业详情页签：每家上市公司也可单独导出自己的诊断结果单页。
4. HTML 均为自包含单文件，双击用浏览器打开后按 Ctrl+P 即可另存为 PDF。

六、打不开怎么办
----------------
1. 检查 4 个文件是否都在同一个文件夹里。
2. 检查是否已安装 Python 3.9 及以上版本，并勾选“Add Python to PATH”。
3. 若黑窗口一闪而过，可在命令行手动启动查看错误：
      cd /d 本文件夹路径
      .venv\Scripts\python.exe -m streamlit run DIAGNOSEX.py --server.port 8502
4. 若端口 8502 被其他程序占用，run_DIAGNOSEX.bat 会自动尝试释放；
   若仍失败，请把黑窗口里的错误文字复制给开发者。

七、免责说明
------------
